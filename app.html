Cómo funciona

Registra cuánto has aportado, descontando las retiradas, y el valor actual de cada inversión. Actualiza los importes manualmente: no se consultan cotizaciones en tiempo real.

El valor actual se suma una sola vez al total de activos de tu patrimonio.

La ganancia o pérdida es el valor actual menos el dinero aportado neto. El porcentaje compara esa diferencia con lo aportado; no es una rentabilidad anualizada y no incluye dividendos retirados.

Si no conoces lo aportado, puedes dejarlo vacío. Verás el valor actual, pero no un resultado calculado con datos incompletos. Guardar una inversión no crea un gasto ni un movimiento.

Privacidad y almacenamiento

FIEXEA guarda los datos y la sesión necesarios para prestar sus funciones. Cuando inicias sesión, tus datos financieros se sincronizan con tu cuenta. Registramos un identificador y las fechas de la prueba para gestionar su vigencia. No utilizamos publicidad opcional. Consulta cómo funciona este almacenamiento o continúa.

Almacenamiento funcional

FIEXEA usa localStorage para guardar los datos financieros en este dispositivo, tus preferencias y la sesión de acceso. Cuando inicias sesión, los datos financieros también se sincronizan con tu cuenta. localStorage es almacenamiento del navegador y no una cookie HTTP. FIEXEA no activa categorías opcionales de analítica o publicidad.
